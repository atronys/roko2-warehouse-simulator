# ROKO2 — симулятор складского робота

Программная модель колёсного робота **ROKO2**, который автономно перемещается по складу 30×30 м со стеллажами и доезжает до выбранного стеллажа, следуя вдоль стен. Учебно-исследовательская работа студента (УИРС).

## Возможности

- Кинематическая модель с рулевым управлением (велосипедная модель / модель Аккермана)
- PD-регуляторы скорости и угла поворота руля, PID-регуляторы в навигационном алгоритме
- Моделирование шумов датчиков: гироскоп, одометрия, ГНСС, три лазерных дальномера (передний, левый, правый)
- Навигация по правилу следования вдоль стены («левой/правой руки») без GPS — счисление пути
- Конечный автомат навигации: движение вдоль стены → подъезд к стеллажу → финальное позиционирование
- Детекция столкновений со стенами и «застревания» с автоматическим манёвром заднего хода
- GUI на DearPyGui: карта склада, траектория, графики курса, скорости и показаний дальномеров, выбор стеллажа (1–24), добавление собственных стен

## Структура репозитория

| Файл                 | Описание                                                        |
| -------------------- | --------------------------------------------------------------- |
| `Roko2.py`           | Модель робота: динамика, PD-контроллеры, датчики с шумами       |
| `Parameters.py`      | Класс параметров состояния робота                               |
| `maze_generator.py`  | Карта склада 30×30 м, стены, стеллажи, виртуальные «датчики»    |

| `Simulator.py`       | Ядро симуляции: цикл «измерение → управление → движение»        |
| `simulate.py`        | Запуск симуляции в консольном режиме                            |
| `simulation_gui.py`  | Запуск симуляции с графическим интерфейсом                      |

## Запуск

```bash
pip install -r requirements.txt
```

### Режим с GUI

```bash
python simulation_gui.py
```

В окне управления выберите номер стеллажа (1–24), при необходимости задайте время симуляции, шаг по времени и собственные стены, затем нажмите **▶ Start**.

### Консольный режим

```bash
python simulate.py
```

Стеллаж выбирается вводом номера в консоль. По завершении строятся графики траектории и параметров движения.

## Как устроена навигация

Робот стартует из точки (2.5, 2.5) и не знает карту склада. Он:

1. следует вдоль стены, удерживая заданную дистанцию по боковому дальномеру (правило «левой руки»);
2. обнаруживает стеллаж по изменениям показаний дальномеров;
3. выполняет подъезд и финальное позиционирование у стеллажа;
4. при застревании или угрозе столкновения выполняет манёвр заднего хода и продолжает движение.

Все измерения зашумлены, поэтому алгоритм работает только по счислению пути и показаниям дальномеров — без глобальной навигации.
